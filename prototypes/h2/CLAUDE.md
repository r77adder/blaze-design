# H2 prototype — local rules

These rules apply to anything inside `prototypes/h2/`. They override or extend the repo-level CLAUDE.md.

## Hard rules

1. **Never use all-caps for labels.** No `textTransform: 'uppercase'` and no manually-uppercased strings on visible UI labels, section headers, eyebrows, badges, or pill text. Use sentence case or title case. The eye reads mixed case faster and uppercase screams. (Existing all-caps usages elsewhere in the H2 prototype are legacy — clean them up if you touch them, but don't go on a sweep just for this rule.)
